A robot vacuum's deadpan excuse for eating a sock: it was a single sock, alone on the floor, so the vacuum adopted it — into its dustbin. `main.ts` writes that one short funny line, deterministically, to `/output/entry.txt` for make.fun's One-Liner Laugh Lab bounty.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes one line to `/output/entry.txt` and nothing else; no network, no secrets, no files outside this repo.
